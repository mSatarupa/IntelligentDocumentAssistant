#  Intelligent Document Assistant

## Overview

This is a powerful **Retrieval-Augmented Generation (RAG)** based application that allows users to upload documents and ask questions about them in natural language.

It combines **FastAPI**, **FAISS**, and **LLMs** to deliver fast, context-aware answers from your own data.


##  Features

* Upload multiple document formats (PDF, TXT, DOCX, CSV, etc.)
* Semantic search using embeddings
* Context-aware answers using LLM
* Fast responses with optimized RAG pipeline
* Clean and modern UI
* Automatic indexing after upload
* Local vector storage (FAISS)

---

## Tech Stack

* **Backend:** FastAPI
* **Vector DB:** FAISS
* **Embeddings:** sentence-transformers (MiniLM)
* **LLM:** Groq API (LLaMA models)
* **Frontend:** HTML, CSS, JavaScript
